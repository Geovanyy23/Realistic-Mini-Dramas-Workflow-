## How to use them

- **The AI producer** can imitate these to see the expected quality and density: a hook in S01, one action and at most one ≤8-word line per shot, motion from the first frame, a twist at about 70%, and a payoff ending. The workflow does not require reading these files.
- **A person** can paste a pack into VideoExpress shot by shot, field for field:
  1. Make the character reference images and save each one with **+ Consistent Character**.
  2. For each shot, set the settings from the pack's table, paste the **Image Prompt**, click **Create Image**, paste the **Video and Audio Prompt**, set **Manual Video Length** (4 s or 5 s), uncheck the public gallery, then click **Create Video**.
  3. Assemble S01→S[N] on track 1, click **Auto Align Clips**, trim each clip to its listed target, align again, then Save and Export.
- **New stories:** keep the structure, then swap the Character Bible, locations and beats.

Trim targets add up to roughly the target length (≈ 44.6 s, 29.6 s and 29.4 s). Generated clips vary, so trim by what's actually on screen and use the targets as a guide.
