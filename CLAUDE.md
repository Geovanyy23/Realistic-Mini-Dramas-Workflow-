# CLAUDE.md

This repository is a prompt package for making fast-paced 9:16 mini dramas in VideoExpress. It contains no code to run.

- Follow `SYSTEM_PROMPT.md` exactly, starting at Step 1 (Intake).
- Use a browser: the built-in browser in the Claude desktop app, or Claude in Chrome. Open https://app.videoexpress.ai/.
- Do not run shell commands, tests or scripts. Do not do a capability audit, model verification or approval gates. Go straight from intake to production.
- Ask the user only for the intake answers, a sign-in, or a Terms/credits screen they must click themselves.
- References: `skills/realistic-mini-dramas/references/videoexpress-ui-map.md` (exact controls) and `fast-pacing-and-trim.md` (pacing and dead-air trimming). Example storyboards are in `examples/`.
